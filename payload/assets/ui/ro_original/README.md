# RO original asset staging area

In diesen Ordner gehören ausschließlich Ressourcen aus einem Client, zu dessen
Nutzung und Bearbeitung der Projektinhaber berechtigt ist.

* `source/` enthält unveränderte Extrakte mit ursprünglichen Dateinamen.
* `runtime/` enthält reproduzierbar abgeleitete Godot-Laufzeittexturen.
* Binärdateien erst nach Prüfung der Lizenz- und Repository-Größenregeln
  einchecken.

Die vollständige Anforderung, Pfadzuordnung und Importregeln stehen in
[`docs/RO_PRE_RENEWAL_UI_ASSET_INTAKE.md`](../../../docs/RO_PRE_RENEWAL_UI_ASSET_INTAKE.md).
